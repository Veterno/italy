# Италия — интерактивный географический атлас

Адаптивный русскоязычный сайт для урока географии. Работает на телефонах Android, iPhone, планшетах, компьютерах и в обычных современных браузерах.

## Что входит в сайт

- Стартовая страница: население, площадь, регионы, ЭГП, специализация, хозяйство.
- 13 тематических слоёв интерактивной карты: географическое положение и транспорт; рельеф; горы и вулканы; климат; реки и озёра; моря и побережья; национальные парки; размещение населения; хозяйство; специализация; сельское хозяйство и пищевая промышленность; туризм; полезные ископаемые и энергетика.
- Интерактивные метки и подписи, поиск объектов по всем слоям, перетаскивание, масштабирование, управление касаниями и колесом мыши.
- Светлая и тёмная темы с запоминанием выбора.
- Презентация на 15 слайдов без упоминаний источников: можно листать прямо на сайте, а также скачать файл PowerPoint.
- Полностью русскоязычный интерфейс.

**Важное уточнение:** области и некоторые маршруты на учебной карте показаны схематично, а контур страны — по упрощённой географической основе. Для точной навигации использовать карту нельзя.

## Публикация на GitHub Pages — без установки программ

1. Скачайте архив `Италия_сайт_GitHub_Pages.zip` и **распакуйте его**.
2. Создайте новый публичный репозиторий на https://github.com/new, например `italy-atlas`.
3. На странице репозитория выберите **Add file → Upload files** и загрузите **все файлы и папки из распакованного каталога `italy_site`**: `index.html`, `style.css`, `app.js`, `assets/`, `slides/`, `downloads/`, `README.md`. Не загружайте архив вместо файлов.
4. Нажмите **Commit changes**.
5. Откройте **Settings → Pages**.
6. В разделе **Build and deployment** выберите **Deploy from a branch**, ветку **main**, папку **/(root)**, затем **Save**.
7. Адрес сайта будет похож на `https://ИМЯ-ПОЛЬЗОВАТЕЛЯ.github.io/italy-atlas/`. GitHub покажет точную ссылку на странице **Pages**.

Сайт использует **относительные пути** (`assets/...`, `slides/...`, `downloads/...`), поэтому корректно работает как по адресу пользовательского репозитория, так и на собственном домене.

## Просмотр на компьютере

Можно просто открыть `index.html` в браузере. Никакие сборщики, пакетные менеджеры и серверы не нужны.

Для проверки через локальный веб-сервер (при наличии Python):

```bash
python -m http.server 8000
```

Затем откройте `http://localhost:8000`.

## Структура проекта

```text
italy_site/
├── index.html                 — вся разметка, включая контуры карты
├── style.css                  — адаптивная верстка и темы
├── app.js                     — карта, поиск, взаимодействия, слайд-шоу
├── assets/
│   ├── значок.svg             — значок сайта
│   ├── рим.webp               — иллюстрация для главной
│   ├── милан.webp             — иллюстрация раздела о хозяйстве
│   ├── побережье.webp         — иллюстрация заключения
│   ├── альпы.webp             — дополнительное изображение
│   └── еда.webp               — дополнительное изображение
├── slides/
│   ├── 01.webp ... 15.webp    — полные изображения слайдов
│   └── 01-mini.webp ...       — миниатюры слайдов
└── downloads/
    └── Италия_презентация_без_источников.pptx
```

Дополнительных платных сервисов, ключей доступа, API и внешних JS-библиотек нет. Для работы карты не нужен интернет после загрузки сайта. GitHub Pages предоставляет статический хостинг.

## Редактирование

- Цифры и описания на главной: `index.html`.
- Цвета, оформление, расположение блоков: `style.css`.
- Географические объекты и тексты карты: массив `темы` в начале `app.js`.
- Слайды: файлы в папке `slides/` и файл PowerPoint в `downloads/`.

Данные численности населения на главной относятся к **1 января 2026 года**, площадь — к официальным показателям Европейского союза. Перед будущими школьными выступлениями при необходимости обновите цифры.
